SIGame Theme Editor — тестовая Windows x86 сборка

Запуск:
1. Скопируйте всю папку целиком.
2. Запустите SIGame.exe.
3. Откройте Настройки → Дизайн → Открыть Theme Editor.
4. Во время игры редактор также открывается кнопкой 🎨 в левом верхнем блоке студии.

Что проверить:
- все пять разделов и десять состояний live preview;
- загрузку TTF/OTF шрифтов (список не должен содержать системные шрифты Windows);
- адаптивный и фиксированный размер текста;
- выравнивание слева, по центру и справа;
- включение и отключение тени текста;
- показ рамок и режим «Только текст на фоне»;
- фон, ширину и отступы вопроса;
- оформление и состояния игроков;
- сохранение, загрузку, дублирование, импорт, экспорт и удаление тем;
- немедленное применение изменений к открытому игровому экрану;
- повторный запуск с восстановлением выбранной темы;
- закрытие Theme Editor и SIGame без оставшихся дочерних процессов WebView2.

Сборка self-contained и содержит .NET runtime. Для Theme Editor требуется установленный Microsoft Edge WebView2 Runtime.

При отчёте об ошибке приложите версию Windows, версию WebView2, скриншот, выбранную тему и точные шаги воспроизведения.
